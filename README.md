## 📖 About

Zoom Mod adds a smooth, optionally scrollable zoom to any Minecraft build without OptiFine, with configurable zoom level and FOV transition speed.

---

## ✨ Features
<a name="features"></a>

- **Smooth Zoom** — cinematic zoom-in animation.
- **Scroll Zoom** — mouse wheel adjusts zoom level.
- **Max Zoom** — configurable from 2x to 50x.
- **FOV Speed** — transition speed slider.
- **No OptiFine Needed** — standalone Fabric/Forge mod.
- **Toggle Key** — hold or toggle mode.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
